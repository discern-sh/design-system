# Licences

The three bundled font families ship under the SIL Open Font License 1.1; each file here is the licence text as the package redistributes it beside `assets/fonts/`.

- `Inter-OFL.txt` covers `fonts/inter.woff2` (Inter, the body, interface, and marketing face).
- `Crimson-Pro-OFL.txt` covers `fonts/crimson-pro-roman.woff2` and `fonts/crimson-pro-italic.woff2` (the display fallback behind Iowan Old Style).
- `JetBrains-Mono-OFL.txt` covers `fonts/jetbrains-mono.woff2` (the code face).

Keep these with the fonts when a prototype ships them. The package itself is Apache-2.0.
