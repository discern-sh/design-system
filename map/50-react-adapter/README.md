# React adapter

The optional Adapter behind `./react` ([`react.ts`](../../src/react.ts)): the 18.3+ peer contract, build-time static rendering of the public class contract, and how the neutral core stays free of React.

Diagram is the projection-sensitive exception that proves the boundary rather than weakening it. [`Diagram`](../../src/components/editorial/diagram/diagram.tsx) imports the neutral generated validation/layout authority, maps its conformant scene directly to React SVG elements, and uses Component CSS against live public semantic Tokens. It does not call `renderDiagramSvg`, inject XML, accept child drawing primitives, or expose accessibility and geometry attributes that could replace the package contract. `useId()` gives the structural description a collision-free identity for repeated static instances. The neutral `./diagram` graph never imports this adapter.

Compose meaningful visible figure prose outside the SVG: `DataFigure` owns the visible heading, caption, source, and legend while `Diagram` owns the image's required accessible name and structural description. A standalone build artifact uses `renderDiagramSvg` through `./diagram` instead, because external SVG cannot inherit this adapter's live Token context.
