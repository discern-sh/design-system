# React adapter

The optional Adapter behind `./react` ([`react.ts`](../../src/react.ts)): the 18.3+ peer contract, build-time static rendering of the public class contract, and how the neutral core stays free of React.

Diagram is the projection-sensitive exception that proves the boundary rather than weakening it. [`Diagram`](../../src/components/editorial/diagram/diagram.tsx) imports the neutral generated validation/layout authority, maps its conformant scene directly to React SVG elements, and uses Component CSS against live public semantic Tokens. It does not call `renderDiagramSvg`, inject XML, accept child drawing primitives, or expose accessibility and geometry attributes that could replace the package contract. A focusable local viewport provides horizontal overflow while retaining intrinsic scene geometry. The SVG carries its structural description directly through `<desc>` and `aria-description`, so repeated static instances need no generated relationship IDs and cannot collide. The forwarded ref, consumer `id`, and consumer class address the SVG. The neutral `./diagram` graph never imports this adapter.

Compose meaningful visible figure prose outside the SVG: `DataFigure` owns the visible heading, caption, source, and legend while `Diagram` owns the image's required accessible name and structural description. A standalone build artifact uses `renderDiagramSvg` through `./diagram` instead, because external SVG cannot inherit this adapter's live Token context.

CopyButton renders the [static copy contract](../40-runtime-emitter/static-copy.md). Its selected browser behaviour owns clipboard writes in static output and live React hosts; React owns props and label/icon markup. Load the emitted script in either host.

ThemeToggle carries the same split as two typed prop shapes rather than one that has to be faked, and `onThemeChange` chooses between them. Supplying it keeps a live React host in charge of resolution, persistence, and root application; omitting it renders the [static theme contract](../40-runtime-emitter/static-theme.md) instead, so a build-time page gets a working control without a handler that does nothing. The opt-in attribute exists only in the static shape, which is what keeps the behaviour and React from both answering one activation.
