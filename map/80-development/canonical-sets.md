# Canonical sets

Shared facts have one authority. Consumers derive their representation from that authority or enter a parity guard that fails on drift.

| Fact                                       | Authority                                                                                                             | Consumers & bindings                                                                                                                                                                                   | Fails on drift                                                                                                                                      |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Catalogue purpose vocabulary               | `cataloguePurposes` in [`src/types/component-meta.ts`](../../src/types/component-meta.ts)                             | Metadata memberships use the closed type. [`styleguide/app.tsx`](../../styleguide/app.tsx) handles labels and filters exhaustively.                                                                    | `Catalogue purposes are closed, selective, and guidance-backed` in [`tests/catalogue_instrument_test.ts`](../../tests/catalogue_instrument_test.ts) |
| Catalogue Component inventory and identity | Component `*.meta.ts` files under [`src/components/`](../../src/components/)                                          | [`scripts/build.ts`](../../scripts/build.ts) discovers Components and generates the Catalogue registry, selection snippets, React export names, and example enrollment.                                | `component metadata auto-enrols React and runtime surfaces` and `Catalogue selection snippets and state fragments derive from the registry`         |
| Catalogue prop and variant evidence        | Public declarations in each Component's `*.tsx` source                                                                | [`scripts/build.ts`](../../scripts/build.ts) reads one `deno doc --json` graph. The generated registry feeds [`styleguide/app.tsx`](../../styleguide/app.tsx); source unions carry an omission reason. | `Catalogue prop evidence is source-derived and complete`                                                                                            |
| Named Catalogue state fragments            | Component slug Metadata plus `catalogueStates` in the Component's `*.examples.tsx`, with generated `default` fallback | [`styleguide/app.tsx`](../../styleguide/app.tsx) derives fragment IDs and permalinks. | Catalogue package identity                 | `version` in [`deno.json`](../../deno.json)                                                                           | [`scripts/build.ts`](../../scripts/build.ts) generates `packageVersion`; the toolbar and conformance sheets render it.                                                                                 | `Catalogue version and composition source share their authorities`                                                                                  |
| Composition preview and copyable source    | Each structured recipe definition in [`styleguide/compositions.tsx`](../../styleguide/compositions.tsx)               | `defineRecipe` passes the same definition to the preview renderer and source renderer.                                                                                                                 | `Catalogue version and composition source share their authorities`                                                                                  |
