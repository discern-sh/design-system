# Diagrams

The diagram subsystem owns semantic, documentation-scale diagrams between author data and presentation. [`src/diagram/mod.ts`](../../src/diagram/mod.ts) is the published React-free `./diagram` boundary: authored spec types, `diagramAltText`, `describeDiagram`, supported-kind Metadata, and `renderDiagramSvg`. It deliberately does not export the caller-authored `DiagramScene` escape hatch, validation/layout dispatch, generated fixtures, or terminal machinery. The package root remains unchanged.

[ADR-0028](../_adr/0028-own-diagrams-as-typed-semantics-and-neutral-scenes.md) records why typed specs, a closed scene, generated built-in kinds, description-first terminals, and independent SVG postures form one boundary. The generated dispatch under [`src/generated/`](../../src/generated/) validates once for each projection, then feeds a kind's deterministic layout and description. Universal scene validity belongs to [`conformance.ts`](../../src/diagram/conformance.ts); `flow` owns only its semantic validation, rank layout, complete description, and representative fixtures under [`src/diagram/kinds/flow/`](../../src/diagram/kinds/flow/).

## Projection boundary

[`renderDiagramSvg`](../../src/diagram/svg.ts) returns one complete byte-stable SVG document and performs no I/O. Canonical root attributes, `<title>`, `<desc>`, embedded style, canvas, connectors, and nodes have fixed order. Semantic text remains escaped `<text>`; explicit arrowhead polygons avoid global IDs, external definitions, and `context-stroke`. Light and dark modes resolve the package's public diagram Tokens to literal values. Adaptive embeds light as its deterministic fallback and a self-contained dark `prefers-color-scheme` rule. The asset uses documented system stacks and conservative package geometry because an external `<img>` inherits neither page custom properties nor page fonts.

[`roles.ts`](../../src/diagram/roles.ts) is the paired style authority. Node bundles keep surface, border, primary ink, annotation ink, and a non-colour shape cue together; connector bundles keep stroke, marker, and solid-or-dashed treatment together. It maps those meanings onto existing public semantic colour Tokens from [`tokens.ts`](../../src/tokens/tokens.ts), avoiding component-specific aliases in every emitted runtime. The standalone serializer resolves the same names to literals, while [`diagram.css`](../../src/components/editorial/diagram/diagram.css) consumes them live. Themes move these Tokens and never fork Component CSS.

[`Diagram`](../../src/components/editorial/diagram/diagram.tsx) is the Editorial React projection. It maps the conformant scene directly to semantic SVG elements, never parses or injects the serializer string, and admits no caller SVG, coordinates, markup, child labels, accessibility overrides, or arbitrary style. A per-instance description identity keeps repeated diagrams collision-free. Required spec title and summary name the image and the full structural description retains every relationship, but neither becomes visible canvas prose. DataFigure owns visible title, caption, source, and legend when a document needs them; Backdrops remain disposable Artwork, while bespoke illustrations and interactive explainers remain consumer-owned.

[`renderDiagramCli`](../../src/components/editorial/diagram/diagram.cli.ts) is the generated CLI Component renderer. Description mode always formats the universal description through the existing Theme, text, layout, and rhythm authorities. Auto mode asks [`diagram-cli-registry.ts`](../../src/generated/diagram-cli-registry.ts), whose callable enhanced imports are generated only into the `./cli` graph from each kind's Metadata. `flow.cli.ts` accepts small linear and branching flows inside explicit width, node, edge, rank, branch, return-edge, and wrapping limits. Any refusal is typed data and routes to the exact description formatter; it never crops, abbreviates, or drops a fact.

The Catalogue enrols Diagram's live SVG, standalone light/dark assets, DataFigure composition, long-label case, enhanced CLI frames, and description/narrow fallbacks from the Component anatomy. Browser guards render the real system stacks at narrow and wide sizes in both Themes, check text against the viewBox, reject connector intersections, and load the serialized SVG through an external `<img>`.
