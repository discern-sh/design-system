## Background

Waves 1A and 2A own everything below the public surface: the two-family codegen, the promoted shared authorities, the numeric and glyph authorities, the series palette spike, `ChartScene` with its conformance proofs, and the `bar` kind's neutral core. Nothing chart-shaped is public yet. This wave proves the risky proposition: one `ChartSpec` can become a high-quality standalone SVG, a live token-themed React chart, and a terminal frame that tells the numeric truth — landed atomically as one vertical slice, because publishing any piece alone would either violate the fixed Component anatomy or ship a contract without its guards.

The static SVG is the primary artifact for ordinary Markdown and must remain useful opened directly or rendered as `<img>`, where page custom properties cannot cascade. The React Component is a separate scene projection using live tokens; it never injects the serializer's XML string. The required accessible title and summary name the image and feed its description but never become visible canvas headings — `DataFigure` remains the optional owner of visible title, legend, caption, and source, and this wave teaches it to accept spec-derived series legends. The terminal frame carries the `exact` honesty tier: `bar` earns an enhanced frame precisely because every authored value is printed beside its bar, so the frame is genuinely lossless within a declared width envelope and declines with a typed reason outside it. The described data table is the universal fallback, a first-class reading experience rather than a punishment.

## Public contract to deliver

- A framework-neutral `@discern-sh/design-system/chart` entrypoint exports the `ChartSpec` union and per-kind authoring types, kind Metadata and the generated author guide, `chartAltText` (derived from title and summary **only** — never data values), `describeChart`, `renderChartSvg` with documented option/result types, and the chart error types. It imports neither React nor terminal modules.
- `--discern-color-series-1..6` are documented public tokens with authored light and dark values, automatic terminal derivation, and machine-checked palette safety. Browser series tokens are consumer-overridable custom properties; terminal series colours are package-authored only — a documented permanent asymmetry.
- `@discern-sh/design-system/react` exports one `Chart` Component accepting a `ChartSpec`, composing naturally as `visual={<Chart spec={spec} />}` inside `DataFigure` without duplicating figure semantics.
- `@discern-sh/design-system/cli` exports the generated `renderChartCli` Component renderer. Auto mode tries the `bar` kind's exact frame and otherwise renders the described data table; callers may request the stable description mode.
- `DataFigure` accepts spec-derived series legend items in both projections without breaking any existing consumer of the current four-tone legend.

## Constraints

- One spec, validation boundary, layout, scene, accessibility authority, and generated kind registry feed every projection. SVG, React, and terminal code differ only at projection.
- The neutral `./chart` graph and `chart.cli.ts` never import React; the CLI renderer performs no I/O, environment read, clock read, or interaction. This wave is strictly static — no chart behaviour scripts (the `behavior_script` standard's ceiling makes v1 static by design), no interactivity of any kind.
- Never exceed the declared honesty tier: `bar` is `exact`, so every authored value prints in every accepted frame; anything less is a decline, and nothing crops, abbreviates, resamples, or silently drops a fact. `chartAltText` derives from title and summary only.
- Semantic state tones are never recruited as series colours; every series slot pairs colour with a non-colour cue in every projection. The 2A locale guard (banning `Intl.NumberFormat`/`Intl.DateTimeFormat`, `toLocaleString`, `toFixed`, and `Date` construction from the chart graph) stays exactly as scoped — neither widened to the CLI graph nor loosened.
- Never hand-edit generated files: change sources and run codegen. Zero new dependencies. No copied code from surveyed tools — the bar frame technique is implemented independently, with provenance recorded where a source materially shaped the result.
- Preserve the seven design principles (`map/00-orientation/design-principles.md`); override one only through an ADR. Never loosen a standard to pass; when your change genuinely moves a number, report it as an owner decision.
- Use focused atomic commits, one logical step each. After the final edit run `discern_prepare`, commit the clean tree, then run `discern_done` once on the committed HEAD. Keep the Catalogue server alive after the gate.
