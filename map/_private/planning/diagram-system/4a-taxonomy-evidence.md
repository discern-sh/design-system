# Diagram kind taxonomy evidence

This note records the read-only corpus check that precedes the Wave 4A shared contract. The source material lives in the sibling discern repository; the package examples below stay generic and do not copy its prose or artwork.

| Reader's task                                                       | Corpus cases                                                                                                                                                                                                                                                                                  | Kind           | Evidence judgment                                                                                                                                                                                                                             |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Follow a process, decision, or bounded state transition             | The quality-gate stages and retry path in `project/map/00-orientation/system-map.md`; the worktree start/update/done/accept lifecycle in `project/map/30-worktrees/lifecycle.md`                                                                                                              | `flow`         | Reference map. Authored branches and return edges are the facts, so the existing grammar is sufficient; no separate state kind is justified.                                                                                                  |
| Locate parts inside a bounded system and trace stable relationships | The binary/router/engine/config topology and bundled-source/install boundary in `project/map/00-orientation/system-map.md`; the protocol, envelope, and engine-layer boundaries in `project/map/70-reference/mcp-and-results.md` and `project/map/50-engine-internals/the-result-envelope.md` | `architecture` | Reference map. Ownership boundaries, stable roles, and labelled relationships are materially different from process order.                                                                                                                    |
| Revisit an ordered practice that repeats                            | The day-to-day status/prepare/test/done loop in `README.md` and `project/map/10-getting-started/walkthrough.md`; the observe/recommend/guard/review improvement loop in `project/map/20-quality-gate/improvement.md` and `project/map/80-development/reviewing-terminal-output.md`            | `cycle`        | Reference map. The repeat and authored stage order are semantic; a flow with a return edge can represent a small state machine but does not communicate a recurring practice or central shared concept as directly.                           |
| Reconstruct who communicates what, and in which order               | The owner/agent/discern consent relay during setup in `project/map/10-getting-started/walkthrough.md`; the caller/authority/journal/Git exchange during interrupted acceptance in `project/map/30-worktrees/acceptance-recovery.md`                                                           | `sequence`     | Reference chronology. Stable participants and ordered calls, returns, and notes are the facts; topology alone would erase temporal order.                                                                                                     |
| Compare bounded calendar spans and gates                            | The launch-to-90-days, on-signal, and year-two plan in `project/map/_private/maintainer/discern-monetization-strategy.md`; the staged Core/Pro/Team validation and launch plan in `project/map/_private/maintainer/discern-desk-commercial-strategy.md`                                       | `timeline`     | Reference plan once an author binds the phases to explicit ISO dates. Duration bars and dated gates are distinct from both dependency flow and the Editorial Timeline Component's narrative events. An undated roadmap remains prose or flow. |

The corpus also contains physical schematics, atmospheric artwork, and interactive product explanations under `art/` and the site sources. Those ask the reader to build intuition through a spatial metaphor or interaction. They remain consumer-owned rather than expanding Diagram or the semantically disposable Artwork group.

The five grammars therefore remain a closed, reference-oriented set. A case that needs coordinates, arbitrary nesting, activation bars, illustration, animation, or controls is evidence that Diagram is the wrong surface, not that the library needs another escape hatch.
