# Distinct voices, shared material craft

Reading keeps the serif display role and sustained editorial rhythm. Product marketing uses the separate marketing headline role, a clear benefit, recognisable symbols and an immediate next action. Operational surfaces use UI hierarchy, aligned controls and explicit status. The relationship comes from shared edges, spacing, type quality and control feedback; a hero or animation is not needed to reveal it.

The [three complete specimens](../../catalogue/compositions/signature-specimens.tsx) show these uses through ordinary Catalogue Compositions and the existing review route. Their recipe entries supply the shared TSX and layout CSS as copyable consumer files. [The minimal consumer](../../scripts/signature-consumer.tsx) emits public package CSS and fonts and renders the build-time adapter without Catalogue CSS, JavaScript or hydration. Run that script after the ordinary build to inspect its light and dark HTML under `dist/signature-consumer/`.

## Select the ingredient at its owner

| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Marketing hierarchy | `--discern-font-marketing`, `--discern-font-weight-marketing`; HeroBlock `layout="statement"`; MarketingSection `spacing="compact"` | Put relevance before mechanism. Statement gives the headline, action and supporting symbols one left-aligned sequence. Compact rhythm leaves breathing room between concise sections. EditorialHero, quotations and reading retain their serif roles.                                                                                                          |
| Surface shading     | Card `texture="shaded"`                                                                                                             | Static optical shading for a selected surface. It follows Structure and composes with the existing, independently selected `raised` elevation. Plain remains the default. Repeated cards normally need only this still treatment, or neither treatment.                                                                                                        |
| Press               | Button and SegmentedControl                                                                                                         | A primary Button's vertical travel compresses its hard shadow. Selection, press, focus and unavailability retain separate witnesses. Secondary actions stay flat. There is no pointer-following illumination on controls.                                                                                                                                      |
| Arrival shimmer     | Card `arrival="shimmer"`                                                                                                            | One brief decorative pass when meaningful content arrives. Add the class or mount the card on that event; omit it for ordinary initial grids. The content and state must be complete before the animation. Reduced motion and forced colours omit the pass.                                                                                                    |
| Ambient light       | LightBackdrop, composing Backdrop                                                                                                   | One deliberately selected opening or supporting region. Ambient motion is the default; `motion="still"` opts out for one placement. Reduced motion stops movement and forced colours omit the light. No composition-level toggle is required. Keep foreground content above the plane. Omit the node to remove it locally.                                     |
| Large-icon relief   | Icon `relief` with `fit="contain"`                                                                                                  | The wrapper preserves supplied SVG fill, stroke, paths and accessibility. Intrinsic asset dimensions remain the default. Relief requires contain fitting for an expressive allocation, stays flat below the [Icon CSS threshold](../../src/components/core/icon/icon.css), and disappears in forced colours. Use neither tilt nor repeated small-icon shadows. |

The [source Appearance laws](../../src/tokens/appearance.ts) own shading, highlight, relief shadow and ambient colour. Structure controls static material presence; Emphasis controls illumination. Card, Window and pop remain the elevation hierarchy. Component styles are identical across themes, and optical shading does not introduce a fourth elevation tier.

Light starts monochrome. A selected existing Accent scope contributes a restrained tint; use `data-discern-accent="none"` on LightBackdrop to restore neutral illumination inside an accented composition. This uses the runtime's existing `appearanceScopes: true` contract and leaves the other Appearance axes intact. Pigment tints continue through the same authorities. Lighting is decorative and must not carry success, warning, selection or availability meaning.

SegmentedControl `sizing="content"` keeps equal-width choices together at the start of the allocation, deriving their width from the widest label. Its default `sizing="fill"` fills the allocation and stacks at narrow widths. Both retain native radio selection and visible labels.

VoiceBreak caps its quotation at the large display role so the human aside stays subordinate to the opening. Decorative quotation marks participate in layout; DataFigure gives its visual slot content-owned height instead of reserving a fixed stage. Consumers whose visual needs a minimum height set it on that supplied visual.

## Typography and supplied artwork

The optional font asset selects Inter through a dedicated marketing face. Its features are bound to that face, so body/UI Inter and a consumer's replacement brand font do not inherit marketing alternates. Override `--discern-font-marketing` and its weight locally for a brand; provide the real fallback stack as well. The feature meanings are commented beside the descriptor in [fonts.css](../../assets/fonts.css). [Font ownership tests](../../tests/font_feature_ownership_test.ts) compare actual rendering with the explicit feature bundle.

Icon consumers supply the graphic's paint. An outlined root should declare `fill="none"` and its intended stroke; a filled asset keeps its own fill. `fit="contain"` scales the supplied graphic without editing paths. The [imported example](../../src/components/core/icon/icon.examples.tsx) compares unchanged filled and outlined SVGs at small and large sizes, with and without relief. Labels and decorative hiding remain the existing Icon contract.

## Restraint and verification

A grid of twelve cards should not become twelve competing light animations. Choose one ambient region at most in a local composition unless a rendered comparison demonstrates a reason for more. Static material, clear headings and satisfying controls must work when all optional light, relief and shimmer are omitted.

Review the actual production speed, the complete still, both themes, intermediate Appearance, narrow allocations and enlarged/fallback text. Inspect repeated layers in the existing browser tools. The [material guards](../../tests/material_contract_test.ts) preserve imported paint, small-icon flatness, motion opt-outs and moving gradient coverage. They scan authored stylesheets by mechanism, including independently named future fixtures; owned vector drawings and consumer-authored CSS remain separate contracts.
