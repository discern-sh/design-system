# Selection and task progress

Start with the selection guidance in [SegmentedControl metadata](../../src/components/forms/segmented-control/segmented-control.meta.ts) and [Progress metadata](../../src/components/feedback/progress/progress.meta.ts). These are the published authority for choosing the Components; [Meter metadata](../../src/components/feedback/meter/meter.meta.ts) owns the companion measurement guidance.

SegmentedControl is a form setting. It owns neither routes nor panels. Its [adapter](../../src/components/forms/segmented-control/segmented-control.tsx) renders native radios inside a labelled fieldset, so arrow selection, label activation, reset, disabled exclusion, and submission belong to the browser. Choose a distinct `name` for each logical group in a form; repeat labels freely, but keep each item's submitted `value` stable and unique. A disabled selection can remain visible when a setting becomes unavailable, while native submission excludes it. With no supplied selection, the first enabled item is the initial value; an all-disabled group has no invented selection.

Use `defaultValue` for static HTML and native reset. A consumer already using React can supply `value` and `onValueChange` to own updates. The package emits no selection script; static output from either path remains natively selectable. Optional icons are decorative supplements to visible labels. The [terminal renderer](../../src/components/forms/segmented-control/segmented-control.cli.ts) paints the supplied choice through the shared form frame and owns no input loop or interactive request kind.

Progress means completed work against a total, or waiting when completion is unknown. The [neutral value resolver](../../src/components/feedback/progress/progress.types.ts) owns normalization for both surfaces. Its readable value stays visible beside the task name; `context` adds units or a current step without replacing that value. Waiting carries no percentage or `aria-valuenow`; motion only reinforces its persistent text. Completion does not by itself claim that a task succeeded. Consumers own task updates and live-region announcement frequency, so a frequently updated bar does not automatically flood assistive technology.

For real adoption examples, start with the [selection examples](../../src/components/forms/segmented-control/segmented-control.examples.tsx) and [progress examples](../../src/components/feedback/progress/progress.examples.tsx). [Selection tests](../../tests/segmented_control_test.tsx) exercise actual emitted forms and local allocations; [progress tests](../../tests/progress_test.tsx) verify accessible values, normalization, waiting, and terminal frames. The generated Catalogue review adds local interaction and motion postures to every canonical settled example.
