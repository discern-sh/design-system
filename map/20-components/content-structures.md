# Cards, navigation, and identity at local width

Content-bearing structures spend vertical space to preserve meaning. [Card](../../src/components/display/card/) remains a passive surface: place a heading and essential content first, quiet metadata after them, then a specifically named native action. Multiple actions are siblings, never links nested inside a full-card action. Nested Cards retain the shared flat treatment. The crowded canonical example demonstrates that composition without imposing a new slot API on consumers.

[Tabs](../../src/components/navigation/tabs/) wraps its strip and long labels. It retains its existing tab/panel contract and DOM-order Left/Right, Home/End navigation across rows; it does not become a two-dimensional keyboard grid. [Breadcrumbs](../../src/components/navigation/breadcrumbs/) wraps ordered ancestors and the complete current location, keeping separators attached to their ancestor. Neither needs scrolling or a collapsed-item disclosure to reveal current state.

The [People group](../../src/components/people/) keeps readable names through local wrapping. Avatar is the shared image authority: its decorative monogram remains beneath an optional empty-alt image, while the named outer image role or adjacent visible name owns the meaningful alternative. A failed or loading image therefore retains initials in static HTML, without a client event handler. Consumer-provided custom avatar slots retain responsibility for their own fallback and alternatives. AvatarGroup wraps its explicit population and expands the last count to fit; `max` is a content decision rather than a viewport-dependent hidden count.

Start review with each affected Component's `narrow-content` posture in the [existing review instrument](../60-catalogue/visual-review.md). [Content structure tests](../../tests/content_structure_polish_test.tsx) exercise 240, 390, and 720 CSS pixel local widths at normal and doubled root text, including unbroken metadata, long names, the last selected tab, failed photos, and a three-digit overflow count. This is an allocated-family regression guard, not a claim about arbitrary consumer children or other Component groups. Existing CLI identity and attribution exact-frame tests preserve their terminal contracts.
