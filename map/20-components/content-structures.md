# Cards, navigation, and identity at local width

Content-bearing structures spend vertical space to preserve meaning. [Card](../../src/components/display/card/) remains a passive surface: place a heading and essential content first, quiet metadata after them, then a specifically named native action. Multiple actions are siblings, never links nested inside a full-card action. Nested Cards retain the shared flat treatment. The crowded canonical example demonstrates that composition without imposing a new slot API on consumers.

[Tabs](../../src/components/navigation/tabs/) wraps its strip and long labels. It retains its existing tab/panel contract and DOM-order Left/Right, Home/End navigation across rows; it does not become a two-dimensional keyboard grid. Each label starts on the panel's content edge; its hover fill and keyboard focus ring share one rounded pill that bleeds past the label and stays clear of the divider, on which the selected indicator sits, and the panel keeps its gap outside its own box so the foundation ring never touches the strip. [`core_navigation_polish_test.tsx`](../../tests/core_navigation_polish_test.tsx) guards that alignment and shared geometry. [Breadcrumbs](../../src/components/navigation/breadcrumbs/) wraps ordered ancestors and the complete current location, keeping separators attached to their ancestor. Neither needs scrolling or a collapsed-item disclosure to reveal current state.

The [People group](../../src/components/people/) keeps readable names through local wrapping. Avatar is the shared image authority: its decorative monogram remains beneath an optional empty-alt image, while the named outer image role or adjacent visible name owns the meaningful alternative. A failed or loading image therefore retains initials in static HTML, without a client event handler. Consumer-provided custom avatar slots retain responsibility for their own fallback and alternatives. AvatarGroup wraps its explicit population and expands the last count to fit; `max` is a content decision rather than a viewport-dependent hidden count. Its overlap stays at a fifth of the avatar size, each overlapped monogram centres in the crescent the next disc leaves visible, and the overflow chip keeps the opaque monogram fill.

Identity badges share one grammar. Avatar presence and Agent avatar status sit on an opaque surface underlay inside a surface-coloured cut-out ring, so neither a photo nor the tile shows through. Shape and fill carry state without colour, because the default monochrome theme renders every tone as grey: presence is solid when online, a crescent when away, barred when busy and hollow when offline; agent status is solid when working, half-filled when waiting, barred when blocked, checked when done and hollow when idle. The agent marks are CSS geometry rather than type, so they stay crisp from `xs` to `xl`; the working pulse fades only the fill, never the underlay or ring, and the status word stays in the tile's accessible label. Mention and Agent mention are one chip on the Accent tint ladder (100 at rest, 200 on hover, 300 on press) with the foundation focus ring; only the shape (rounded for people, `radius-sm` for agents) and the sigil differ. Persona, Agent persona and both mentions keep their avatar or sigil beside the first line of a wrapped name, while a one-line name stays centred on its avatar. Byline connector words (the lede and any plain text between authors) share the muted meta tone, so names carry emphasis through their own chips. [Identity and operations geometry tests](../../tests/identity_operations_geometry_test.tsx) guard monogram clearance, the opaque overflow chip, badge opacity and shape distinctness, and first-line alignment.

Start review with each affected Component's `narrow-content` posture in the [existing review instrument](../60-catalogue/visual-review.md). [Content structure tests](../../tests/content_structure_polish_test.tsx) exercise 240, 390, and 720 CSS pixel local widths at normal and doubled root text, including unbroken metadata, long names, the last selected tab, failed photos, and a three-digit overflow count. This is an allocated-family regression guard, not a claim about arbitrary consumer children or other Component groups. Existing CLI identity and attribution exact-frame tests preserve their terminal contracts.
