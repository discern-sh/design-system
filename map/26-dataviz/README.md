# Dataviz

The chart subsystem owns quantitative, documentation-scale charts between author data and presentation: typed `ChartSpec` data validated and laid onto scales, a closed projection-neutral `ChartScene`, and a lossless structural description. It is the second client of the kind-family codegen — a sibling of the diagram family, split by subject: diagrams own identity and topology, charts own quantities on scales. It is also the second client of the shared Markdown image-promotion resolver: [ADR-0031](../_adr/0031-promote-markdown-images-through-one-resource-family.md) records why chart resources ride the one resource-family core rather than a parallel chart-side copy. [ADR-0030](../_adr/0030-own-charts-as-a-quantitative-kind-family.md) records the boundary — why charts are not diagram kinds, the second scene grammar, scene element granularity, the six-slot series colour policy, the terminal honesty ladder (exact and faithful frame tiers), the permanent braille refusal, the binding honesty rules, static-first, the bar orientation hint, and the deferred diverging-bar variant.

The surface is public: [`src/chart/mod.ts`](../../src/chart/mod.ts) is the `./chart` entrypoint, exporting authoring types, `chartAltText`, `describeChart`, kind Metadata with the generated author guide, the closed number format vocabulary, `chartSeriesLegend`, the error types, and the standalone `renderChartSvg` — while deliberately withholding `ChartScene`, the layout dispatch, and `conformChartScene`, so callers author data and never scenes. A release guard keeps that graph local, React-free, CLI-free, and permission-free, and the locale/clock ban rides the same graph. The chart family's terminal projector surface is declared in the family configuration: the generated [`chart-cli-registry.ts`](../../src/generated/chart-cli-registry.ts) maps each kind to its stance, the stance pairing makes a missing projector a generation failure, and [`bar.cli.ts`](../../src/chart/kinds/bar/bar.cli.ts) is the exact-tier projector (every authored value prints beside its eighth-block bar; typed declines route to the described table; terminal bars are always horizontal regardless of the orientation hint).

The Editorial `Chart` Component ([`src/components/editorial/chart/`](../../src/components/editorial/chart/)) projects the same conformant scene to live-token semantic SVG and, through `renderChartCli`, to the terminal; `DataFigure` accepts the spec-derived series legend tones in both projections. Series colour lives in [`tokens.ts`](../../src/tokens/tokens.ts) as the documented public `--discern-color-series-1..6` family — browser-overridable custom properties, terminal-fixed by design — and [`src/chart/palette.ts`](../../src/chart/palette.ts) resolves the paint-role→Token map to literals for standalone assets.

## Where a maintainer starts

Everything lives under [`src/chart/`](../../src/chart/), composed from the shared internal authorities in [`src/internal/`](../../src/internal/) — never from `src/diagram/`:

- **Numerics** — [`decimal.ts`](../../src/chart/decimal.ts) owns scaled-decimal integer arithmetic with half-away-from-zero rounding; [`format.ts`](../../src/chart/format.ts) owns the closed locale-free number format vocabulary; [`scale.ts`](../../src/chart/scale.ts) owns linear and band scales; [`ticks.ts`](../../src/chart/ticks.ts) owns Heckbert 1-2-5 tick selection in integer space. A locale/clock graph guard in [`tests/chart/graph_guard_test.ts`](../../tests/chart/graph_guard_test.ts) bans `Intl`, `toLocaleString`, `toFixed`, and `Date` construction from the chart module graph.
- **Scene** — [`scene.ts`](../../src/chart/scene.ts) declares the closed grammar; [`conformance.ts`](../../src/chart/conformance.ts) proves bounds, containment, clearance, declared z-order, and no undeclared overlaps before any projection sees a scene; [`geometry.ts`](../../src/chart/geometry.ts) pins the visual grammar constants.
- **Kinds** — each folder under [`src/chart/kinds/`](../../src/chart/kinds/) owns the fixed anatomy the family framework enforces; [`scripts/generate.ts`](../../scripts/generate.ts) supplies the chart family configuration and [`scripts/kind-family.ts`](../../scripts/kind-family.ts) generates the spec union, Metadata, registry, dispatch, and export barrel. Budgets, stances, and honesty tiers come from each kind's `*.meta.ts`.
- **Series palette** — the authored light/dark values live only in [`tokens.ts`](../../src/tokens/tokens.ts) as `--discern-color-series-1..6`; [`tests/chart/palette_test.ts`](../../tests/chart/palette_test.ts) is the machine check (CVD separation at its pinned threshold, ANSI 256 distinctness, and the pinned ANSI 16 collapse), pointed at the Token authority through the real derived terminal themes so any palette edit re-runs the proofs.
- **Terminal glyphs** — [`src/cli/glyph-ramps.ts`](../../src/cli/glyph-ramps.ts) owns the eighth-block ramps, the shade ramp with its digit-bin ASCII alternative, the per-slot marker and fill tables, and the N-category proportional block allocator, each Unicode glyph paired with a one-cell ASCII fallback.

The bar kind is the vertical slice; read [`src/chart/kinds/bar/`](../../src/chart/kinds/bar/) end to end to see the full anatomy — spec, validation (zero baseline, negative refusal, declared gaps, proportion totals), scale-driven layout, description, and release corpus — before writing a new kind.

## Relation to neighbours

The [diagram subsystem](../25-diagrams/README.md) shares the kind-family framework and the `src/internal/` authorities but nothing else; neither family imports the other. [Codegen](../30-codegen/README.md) documents the family framework itself. The [CLI subsystem](../70-cli/README.md) owns the text, theme, and capability authorities the future chart frames will compose; the chart core never imports from `src/cli/`.
