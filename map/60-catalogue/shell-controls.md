# Shell controls

The [shell](../../catalogue/shell/catalogue-shell.tsx) owns the common navigation, search, and Appearance interactions. Keep these controls shared across route families; the [ownership seams](ownership-seams.md) identify the separate page owners.

[Appearance presets](../../catalogue/shell/appearance-presets.tsx) are starting coordinates, not themes. They preserve Darkness and Accent so choosing a reading density does not change the user's theme policy. Both the header and Foundations instrument consume that authority. Default restores the non-Darkness axes; each exact axis control also exposes its package default. The [axis parser](../../catalogue/shell/axes-state.ts) owns bounded input and URL parsing. Numeric drafts commit on Enter or blur, invalid drafts remain editable, and Escape cancels an unfinished draft before dismissing its enclosing disclosure. Native sliders admit the same exact coordinates rather than rounding the displayed state to a second grid.

The [Appearance disclosure](../../catalogue/shell/appearance-disclosure.ts) enhances native details. Escape restores its summary; outside pointer interaction closes it and restores hidden focus while letting the new pointer target take focus. Outward keyboard focus closes it without pulling focus backwards. Nested controls retain their native interaction. The panel uses the shared floating-surface roles and scrolls within the viewport.

[Global search](../../catalogue/shell/global-search.tsx) groups the engine's bounded results by the existing route families, retaining ranking within each group and first-match family order. It uses existing representative Component images and literal Glyph previews without mounting specimens. Results remain native links: Tab follows document order, arrow keys move among destinations and back to the query, and Enter follows the focused link. Search reports result counts through a polite status region. Recent destinations mean destinations opened from search; [history](../../catalogue/search/recent.ts) stores only a bounded set of record IDs. Current records supply names and URLs, stale identities disappear, Clear recent removes the saved set, and unavailable storage leaves live search usable.

[Secondary navigation](../../catalogue/shell/navigation.tsx) collapses through buttons embedded in the public DocsNav section-title contract. A collapsed group retains its current destination, so route changes and Back/Forward cannot hide the user's location. Expansion preferences are local conveniences, independent of URL state. The [mobile drawer](../../catalogue/shell/mobile-drawer.ts) shares the same navigation, restores its trigger when closed, and moves to a visible destination when a resize retires the mobile controls.

The shell's [browser journeys](../../scripts/conformance/catalogue/shell.ts) cover narrow portrait, short landscape, desktop, zoom-equivalent reflow, exact drafts and reset, search/recent navigation, dismissal, storage failure, and resize focus. These are semantic and geometry checks; screenshots support human visual judgment rather than serving as a pixel gate.
