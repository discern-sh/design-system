# Component discovery

The directory helps users choose a Component before opening its live specimen. Collection identities precede their generated imagery; search and surface selection stay visible, while the native More filters disclosure contains group, purpose, and optional package behaviour. Active secondary filters open on a shared URL. Reset returns to collections.

Start in [collections.ts](../../catalogue/pages/components/collections.ts) for capability decisions. Availability requires a canonical applicable example and, for CLI, a rendered stance. Package behaviour means the metadata's selected browser runtime behaviour; neither hydration nor a native control implies such a declaration. Counts and membership project the generated registry, so new Components require no discovery inventory.

[Directory cards](../../catalogue/pages/components/directory-card.tsx) consume the canonical representative image and logical dimensions from the generated image authority. The discovery stylesheet frames a thin Core control strip at its logical size, revealing the leading controls through a clipped local frame. Broad compositions remain contained to show structure. Directory imagery is illustrative, not an exhaustive specimen; inspect the detail for every state. Image production and other routes' cards remain independently owned.

[Explorer state](../../catalogue/pages/components/explorer-state.ts) owns reproducible controls. [Return context](../../catalogue/pages/components/return-context.ts) accepts only the local Components directory, rebuilds known state, preserves Appearance, and carries a validated result fragment. The URL itself supports sharing and new tabs. Native result navigation records its result anchor in the current history entry; returning restores that result's visibility and keyboard focus. Filter changes drop the anchor. Unavailable result anchors leave normal page navigation intact.

The extracted [detail navigation](../../catalogue/pages/components/detail-navigation.tsx) and [local navigation](../../catalogue/pages/components/navigation.tsx) preserve this return destination through previous/next travel. Detail controls call the same discovery-owned href helper at their navigation boundary. The helper leaves explicit detail examples and fragments intact; it owns no specimen layout or selection policy.

The focused [discovery tests](../../tests/catalogue_component_discovery_test.ts) guard metadata and URL boundaries. The allocated [browser checks](../../scripts/conformance/catalogue/component-discovery.ts) exercise filtered detail/back/history/new-tab journeys, distance to useful choices, representative framing, and semantic copy reflow.
